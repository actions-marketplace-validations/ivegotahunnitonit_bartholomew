# Bartholomew Protocol — Core Value Proposition & Positioning
**The Deterministic Boundary Between Your Coding Agent and Your Terminal**

---

## 1. What We Actually Own: The Moment Before Execution

When an AI coding agent (Claude Code, Cursor, Windsurf, Copilot, or custom scripts) decides to act, there is a critical decision point:
* The agent has synthesized a terminal command, file modification, or API call.
* It is about to execute it on your machine, your filesystem, or your cloud.

**Bartholomew owns that exact millisecond.**

We are not "AI safety" in the abstract. We are an in-process, deterministic execution firewall that evaluates proposed tool actions against a strict workspace policy in **under 35 microseconds**, allows or vetoes the action, explains the decision, and signs a tamper-proof cryptographic receipt.

## 2. Who Pays & Why

### The Buyer
**Engineering Leads, Platform Leads, and DevSecOps Directors** whose developers are adopting AI coding agents.

### The Job They Hire Us For
> **"Give our engineering team the freedom to move 5x faster with coding agents, while giving leadership the absolute certainty that an agent cannot run an unauthorized command, wipe state, expose secrets, or push flawed code—backed by an auditable compliance paper trail."**

### What They Will Pay For
1. **Shared Team Policy (`.btp/policy.yaml`)**: One version-controlled configuration enforced across every developer's IDE (Cursor, VS Code, Windsurf) and terminal.
2. **Fail-Closed Git & CI Enforcement**: Pre-commit hooks that guarantee un-inspected agent changes never enter main branches.
3. **Centralized Audit Dossiers**: Exportable proof for CISO and SOC 2 Type II compliance reviews detailing every tool proposal, block, and allow.
4. **Hands-On Setup & Support**: Dedicated configuration, zero-disruption tuning, and white-glove onboarding.
